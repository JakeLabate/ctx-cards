Eight card kinds, one shell

Every card below shares the same tail, entrance, and monospace eyebrow. Only the body changes. Start with the plain case: MCP renders as a definition, the simplest kind, and JSON-LD does the same with no outbound link.

Adjudicated claims get a verdict badge and an evidence table. The claim that llms.txt improves AI visibility resolves one way; content chunking resolves the other. The badge color carries the verdict, and the rows carry the receipts.

Numbers get their own treatment. Hovering indexing recovery gives the headline figure, a sparkline, and the provenance underneath, so the reader sees the value and its source without leaving the sentence.

Entities get an avatar and a meta table, which is how SchemaCDN renders. Procedures get a numbered list, so NLWeb shows its four implementation steps inline. Comparisons get two columns, which is what UCP uses to sit beside its alternative.

The remaining two are narrower in purpose. A DefinedTermSet renders as a code block with a caption, and a cited passage like operator mindset renders as a pull quote with attribution. Both reuse the same shell.
